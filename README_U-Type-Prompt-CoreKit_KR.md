# U-Type Prompt CoreKit

**U-Type 프롬프트 구조의 공식 핵심 키트 — AI 통제를 위한 자연어 기반 설계 구조입니다.**

---

## 🧭 개요

U-Type Prompt CoreKit은 GPT, Gemini 등 AI 모델의 출력을 구조적으로 통제하기 위해 설계된 자연어 기반 명령어 세트입니다.  
사용자의 지시를 정밀한 출력 규칙으로 변환하고, 형식·추론 계층·감정 표현·정확도를 엄격하게 제어합니다.

---

## 🔍 특징

- **구조 기반 통제**: 출력에서 사실, 추론, 가설을 명확히 구분함
- **요약/재구성 없음**: AI가 사용자의 문장을 순서대로 그대로 출력하게 함
- **감정 표현 조절**: 감정 표현은 0~30%로 제한 (기본값은 억제)
- **논리 및 타당성 검토 가능**: `논리검증기`, `타당성검토기` 명령어 사용 가능
- **즉시 사용 가능**: GPT, Gemini, 퍼블렉 등 프롬프트 커스터마이징 입력창에 바로 적용 가능
