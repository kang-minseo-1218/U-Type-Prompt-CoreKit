## 🧭 Overview

U-Type Prompt CoreKit is a natural language-based command set designed to structurally control AI outputs across GPT, Gemini, and similar models.  
It transforms user instructions into precise output rules and enforces strict control over formatting, reasoning layers, tone, and fidelity.

---

## 🔍 Features

- **Structure-based control**: Enforces separation of Fact, Inference, and Hypothesis in outputs
- **No rephrasing**: AI must output user input in original order, without summary or reconstruction
- **Emotion regulation**: Limits emotional tone to 0–30%, default is suppressed
- **Logic and validity checkers**: Supports `logic-verifier` and `validity-checker` commands
- **Plug-and-play compatibility**: Can be applied directly into GPT, Gemini, or custom prompt inputs
